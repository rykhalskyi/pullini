Connect an agent with MCP

Pullini ships a local stdio MCP connector (pullini-mcp) that lets an agent create, read, update, delete and share artifacts through the authenticated API. The connector runs on the agent's machine and reads its configuration from the environment.

1. Create a token

The connector authenticates with a personal access token. Create one on the Tokens page and copy the secret (pln_…) — it is shown only once.

2. Run the connector from the repo

From a checkout of the Pullini repository, uv resolves and runs the connector straight from the mcp/ folder — no install step needed: 

uv run --directory /path/to/pullini/mcp pullini-mcp

Point --directory at the mcp/ folder of your clone.

3. Add it to your client

Add a pullini entry to your MCP client's config, passing PULLINI_URL and PULLINI_TOKEN. For opencode, edit ~/.config/opencode/opencode.jsonc: 

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "pullini": {
      "type": "local",
      "command": [
        "uv",
        "run",
        "--directory",
        "/path/to/pullini/mcp",
        "pullini-mcp"
      ],
      "enabled": true,
      "environment": {
        "PULLINI_URL": "{{ pullini_url }}",
        "PULLINI_TOKEN": "pln_xxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyy"
      }
    }
  }
}

Other clients use an mcpServers object with command, args and env: 

{
  "mcpServers": {
    "pullini": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/pullini/mcp", "pullini-mcp"],
      "env": {
        "PULLINI_URL": "{{ pullini_url }}",
        "PULLINI_TOKEN": "pln_xxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyy"
      }
    }
  }
}

Restart the client so it launches the server, then confirm the tools appear.

Tools

  • store_artifact — create an artifact, or overwrite one when slug is given.
  • list_artifacts — list the token owner's artifacts.
  • get_artifact — fetch one artifact (source Markdown, rendered HTML, plain text).
  • update_artifact — change an artifact's title and/or content.
  • delete_artifact — delete an artifact.
  • share_artifact — enable or revoke the unlisted share link.

Agent skill

Alongside the tools, the connector exposes an agent skill as the MCP resource pullini://skill. It is a short Markdown guide covering the bearer-token auth, every artifact endpoint and the authoring rules, so an agent can use the API correctly even without prior knowledge of Pullini. The tools above are convenience wrappers around the same REST API the skill documents.

Read it from any MCP client that supports resources, or ask the agent to load the pullini://skill resource before it starts writing artifacts. The same document is served over HTTP (token required), which is handy for clients without resource support: 

curl -H "Authorization: Bearer pln_xxxxxxxx_yyyyyyyyyyyyyyyyyyyyyyyy" {{ pullini_url }}/api/skill/

The skill is informational only — it grants no access beyond the token it was fetched with, and each token only ever sees its owner's artifacts.

Install from PyPI

Publishing pullini-mcp to PyPI is in progress. Once available, the checkout step above is replaced by: 

uvx pullini-mcp
